
## EDA 

EDA means understanding the dataset before building the ML model 

### Steps of EDA: 

#### 1. Viewing the Data 

  - What columns do we have 
  - What types of data are there in them 

  > We use `head(), tail(), shape, info()` for data viewing. 


#### 2. Summary Statistics

- Quick overview of data
- How data is spread and its central tendency

> We use `mean, median, mode, std, min, max and quartile` for overviewing data.


#### 3. Value Count

- How many unique value are in the column
- Great for categorical (qualitative) data

#### 4. Missing Value Analysis

- Where are the gaps in our data 
- How much data is missing 

#### 5. Visualize 

- We do visualizations of data in this step. 


> We use: 
> - Histogram --> distribution of values 
> - Boxplot   --> outliers and spreads
> - Barplot   --> comparision of categories 
> - Correlation heatmap --> linear relationship between numerical features 
> - Scatter plots   --> bivariate relationship 
>
> for data visualization. 


#### 6. Target Value Finding

- We explore the output variable and find its relation with other variables.

## Importance of EDA

- Helps to understand the data
- Helps to identify mistakes and biases
- Guides the direction of data cleaning and feature engineering
- Help to an overview to our audience
